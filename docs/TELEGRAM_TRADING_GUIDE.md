# 텔레그램 AI 자산비서 & 안전 트레이딩 봇 가이드

본 가이드는 모바일 메신저 **텔레그램**에서 7.1억 원 규모 실자산을 안전하게 모니터링하고, Gemini AI와 대화하여 포트폴리오 리밸런싱을 제안받은 뒤, **인라인 승인 버튼으로 한국투자증권(KIS) 실전/모의투자를 1클릭에 실행**하는 봇의 설정 및 운영 매뉴얼입니다.

---

## 1. 주요 기능

1. **대화형 AI 자산 상담**: 
   - Gemini 2.5 Flash가 포트폴리오(NVDA 28%, GOOGL 18%, TSLA 14% 등) 비중을 기반으로 최적의 분할 매수/매도 제안.
2. **Human-in-the-Loop 명시적 승인 (원천 사고 차단)**:
   - AI는 절대 독단으로 주문을 내지 못하며, 텔레그램 화면에 **`[🚀 NVDA 2주 매수 즉시 실행]`** 인라인 버튼을 생성합니다.
   - 사용자가 손가락으로 직접 터치하지 않는 한 1원도 주문되지 않습니다.
3. **4중 보안 가드레일**:
   - **화이트리스트**: 등록된 단 1명의 Telegram User ID만 명령 수신.
   - **더블 클릭 방지**: 버튼 클릭 즉시 잠금 상태(`[⏳ 주문 처리 중...]`)로 전환되어 멱등성 보장.
   - **5분 TTL 만료**: 5분이 지난 이전 메시지의 버튼은 자동 무효화.
   - **시스템 Risk Guard**: 1회 최대 100주 초과 주문 시 엔진 레벨에서 즉시 강제 종료(`sys.exit(1)`).

---

## 2. 필수 환경변수 설정

봇 실행 전 아래 환경변수를 시스템 또는 `.env`에 설정합니다:

| 환경변수 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `TELEGRAM_BOT_TOKEN` | **필수** | BotFather에서 발급받은 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` (또는 `TELEGRAM_ALLOWED_USERS`) | **필수** | 내 고유 Telegram User ID (화이트리스트 검증용) |
| `GEMINI_API_KEY` | **필수** | Google AI Studio에서 발급받은 Gemini API 키 |
| `GITHUB_PAT` | **필수** | GitHub Actions `workflow_dispatch` 권한을 가진 Personal Access Token |
| `MAX_ORDER_QTY` | 선택 | 1회 최대 허용 주문 수량 (기본값: `100`) |

## 3. 실행 방법

### 로컬 또는 백그라운드 서버 구동
```bash
# 1. 의존성 확인 (표준 라이브러리 및 urllib 기반으로 즉시 실행 가능)
python scripts/telegram_bot.py
```

### 단위 및 E2E 테스트 실행 (무결성 검증)
```bash
python -m unittest tests/test_telegram_trading.py -v
```

## 4. 텔레그램 사용 예시

1. `/portfolio` : 현재 보유 포트폴리오 요약 조회
2. `/status` : 봇 가동 상태 및 Risk Guard 한도 확인
3. **자연어 상담 & 주문**:
   - 사용자: `"구글 비중 조금 늘리고 싶은데 어때?"`
   - AI 응답:
     ```
     현재 구글 비중은 18%로 밸류에이션 매력이 충분합니다. 
     안전하게 2주 분할 매수를 제안합니다.

     📋 [한투 AI 주문 제안 확인]
     • 종목: GOOGL
     • 구분: 매수
     • 수량: 2주 (시장가)
     • 안전 가드: 100주 하드 리밋 검증 완료

     [🚀 GOOGL 2주 매수 즉시 실행]  [❌ 주문 취소]
     ```
   - 사용자가 **`[🚀 GOOGL 2주 매수 즉시 실행]`**을 탭하면 GitHub Actions 러너가 작동하여 KIS 주문이 체결되고 완료 알림이 도착합니다.
